## 0. 定稿结论

**参考图的方向成立，但不能照抄：它画了产品表达，没画宿主边界。** 定稿做三件事：

1. **把“产品壳”做出来**：浅灰底 `#F5F5F7`、浮起的白色 Header、白卡、24px 大圆角、柔和阴影、毛玻璃浮窗、30/70 双区、左栏元主、右栏分身。
2. **把“能信”补上**：三色状态投影（绿=进行中 / 蓝=非工作 / 红=已证实故障）、7 槽位与 5 配额、强确认删除、指纹式 DOM 钩子、禁用原因节点。
3. **把“不能做”拿掉**：工作区新建/归档/删除/下载属于 DSH 宿主，fang 不画灰键；暂停/恢复/重启没有路由，按 `capability-missing` 隐藏；重命名走 `PATCH`，旧宿主 404 时退化为本地别名并**如实告知**。

### 0.2 命名裁决（先对齐，否则实现必走偏）

| 词 | 定义 | 说明 |
|---|---|---|
| **母体** | 正在运行 dsh-Fang 的宿主控制面 | Header 的 Stats、Mother 浮窗、只读会话来源 |
| **元主卡** | 母体控制面主卡（单例） | 左栏顶部固定卡：phase、版本、可达性、“打开门户”；不是工作区卡 |
| **元主槽位** | 母体工作区（workspace）在左栏的只读槽位 | 一行一个工作区；展开显示其会话；显示名可改（别名） |
| **分身卡** | 一个 task/fork 的运行实例 | 右栏；7 个物理槽位、默认 5 个配额 |
| **浮窗** | 毛玻璃模态层（Mother / 确认 / 输入） | 固定位置、焦点陷阱、Esc/遮罩关闭 |
| **派发** | 把工作送到一个分身（红色语义） | 本版没有独立派发路由；红色只给永久删除与已证实故障 |
| **派生** | 新建一个分身（绿色语义） | Header 主 CTA、会话 CTA、双击图标 |

> 冲突说明：`STATE-MODEL` 里的“元主卡”指母体控制面，本文沿用它；参考图里“元主”列表实际是**工作区**，本文称“元主槽位/元主工作区”，并在文案上写“工作区”。两处不能混用同一个词。

### 0.3 与既有契约的关系

- 状态、phase、capacity、`actions` 掩码、ETag/`panelRev` 以 `STATE-MODEL` 为准；本文只消费，不重定义。
- 操作安全、钩子、验收 ID 以 `REVIEW-…v3.0.6-v3.0.7` 为准；本文的 AC 与其 AC7-* 对齐，并补视觉/交互细节。
- v3.0.5 后端缺少的字段，UI 必须**降级而不是编造**：`phase` 用 legacy 投影、`capacity` 标注“估算”、重命名 404 后退化为本地别名。

### 1.3 参考图自身的矛盾（定稿裁决）

| 参考图 | 与契约冲突 | 裁决 |
|---|---|---|
| “＋派生新分身”红色实心，“Mother”绿色实心 | 绿色应表示派生，红色应表示派发/破坏 | 派生改绿色；Mother 改中性描边（打开浮窗不是主操作） |

### 2.2 状态与动作语义

| 语义 | 颜色 | 使用位置 | 禁止 |
|---|---|---|---|
| 进行中（provisioning/starting/resuming/running） | 绿 | 状态 chip、卡左条、分组点、统计点 | 用绿表示“成功/已归档” |
| 非工作（pausing/paused/stopping/completed/archived） | 蓝 | 同上；归档另进读档视图 | 与错误混用 |
| 已证实故障（failed/crashed；running+适配器失联；服务端 stale） | 红 | 状态 chip、异常边、错误通知、删除 | 用红表示“可逆归档” |
| 未知/离线 | 中性灰 | 状态 chip、断线横幅 | 用红冒充崩溃 |
| 派生 | 绿实心 | Header 主 CTA、会话 CTA | 用红/蓝 |
| 配置 | 橘描边/浅底 | 备份、升级、间隔、设置 | 出现在状态 chip |
| 破坏 | 红实心/红字 | 永久删除、强确认 | 用于归档/还原 |

### 2.6 动效

| 场景 | 时长/曲线 |
|---|---|
| 悬停、按钮色 | 120ms ease |
| 展开/折叠、chevron | 160–180ms ease |
| 浮窗进入 | 240ms `cubic-bezier(.22,.61,.36,1)`（opacity + 8px 上移 + 0.985 缩放） |
| Toast | 180ms 进入；4.2s 自动消失 |
| `prefers-reduced-motion` | 全部动画 0.01ms；禁止位移/脉冲 |

### 2.7 主题决策（D7）

参考图是浅色产品界面。v2 **固定浅色**（`color-scheme: light`），不随宿主深色主题漂移：
- 理由：现有三色与白卡阴影在深色下需要重新测对比度；本轮不引入未验证的第四套色板。
- 代价：宿主为深色时控制台仍为浅色，视觉上像“产品内嵌画布”，可接受；深色作为 v3 单独评审（AC 不覆盖）。
- 实现上仍保留 `--fang-*` 变量层，未来加 `[data-theme="dark"]` 只改变量，不改组件。

## 3. 组件规格

所有可交互元素带 `data-btn-id`；状态/健康/新鲜度/任务键使用统一钩子（§6.4）。

### 3.1 Header（`data-zone="header"`）

| 项 | 规格 |
|---|---|
| 结构 | 左：品牌（38px 城门图标 + 23px 标题 + 10.5px 副标）；中：Stats；右：动作区 + 版本胶囊 |
| 容器 | 白底 90% + 18px 模糊、1px 描边、22px 圆角、面板阴影；`position: sticky; top: 0` |
| 动作 | 读档(n)（M-01）→ 临时内容（M-02）→ 刷新（M-03）→ Mother（M-04）→ 派生新分身（M-05，绿实心 lg） |
| 状态 | 刷新中：按钮 `aria-busy`，正文 `aria-busy`；离线：不复用红色，版本胶囊保持；配额满：M-05 显示“配额已满”并 `aria-disabled` |
| 布局 | ≥1240 单行；<1240 Stats 换行独占；<760 动作换行、按钮可拉伸 |
| 文案 | 副标“母体 × 分身 · 三区控制台”；版本 `v3.0.5` 由 mono 胶囊承载 |

### 3.2 Stats（Header 中段）

## 4. 交互与可访问性

### 4.1 双击重命名（状态机）

状态：`idle → editing → saving → idle | error`。

| 事件 | 行为 |
|---|---|
| 双击展示态 | `editing`，预填当前名并全选；焦点进 input；后台轮询暂停渲染 |
| Enter（非 IME） | `saving`；单飞锁，重复 Enter 不重复提交 |
| Esc | 取消，恢复原名，焦点回展示态，0 请求 |
| blur | 延迟 120ms 提交；若已提交/取消则忽略（防双发） |
| 空名 | 不提交，Toast“名称不能为空”，仍停留编辑态 |
| 成功 | 更新名称；Toast；礼貌播报“已重命名为 X”；焦点回展示态 |
| 409 | 回滚原名；Toast“名称已被其他客户端改为 X”；严格播报 |
| 404/405 | 写本地别名；Toast“已保存本地别名（未写回宿主）”；后续重命名仍先试 PATCH |
| 网络错误/5xx | 回滚原名；Toast“重命名失败，已恢复”；严格播报；不得写本地别名冒充成功 |

服务端契约（目标）：`PATCH /fang/api/workspaces/:key`（工作区别名）与 `PATCH /fang/api/tasks/:id`（分身标题，`baseTitleRev` CAS）。回应：200 新 `aliasRev/titleRev`；409 当前值；404/405 路由缺失。分身标题的 rename 入口在 v2 不渲染（宿主未提供 action 掩码），只保留工作区别名。

无障碍：展示态为按钮，可 Tab 到、Enter/F2 进入编辑；input 有显式 label；错误通过 `role="status"`/严格播报；编辑中不打断 IME（composition 期间 Enter 不提交）。

### 4.2 浮窗（Mother / 确认 / 输入）

- 打开：记录 `returnFk`；设置 `S.modal`；锁 body 滚动；渲染背景 `inert` + `aria-hidden`。
- 关闭：Esc、关闭按钮、遮罩点击（mousedown 起点在遮罩）；关闭后解锁滚动、还原焦点到触发元素；若触发元素不存在，焦点落到 Header 的 M-04/M-05。
- 焦点陷阱：Tab/Shift+Tab 在 `[role=dialog]/[role=alertdialog]` 内闭环；初始焦点 = `data-autofocus` 元素（Mother=关闭；确认=取消；输入=输入框）；编辑/输入过程中重渲染优先保持对话框内焦点。
- 只允许一个浮窗；Mother 内的恢复/删除/升级使用**内联确认条**，不叠加第二个对话框。
- 动效 240ms；`prefers-reduced-motion` 下无位移。
- 遮罩点击取消；点击浮窗内部不关闭。

### 4.3 确认删除（分级）

| 等级 | 场景 | 交互 |
|---|---|---|
| none | 派生、打开、复制 | 直接执行 |
| once | 归档、还原、镜像恢复/删除/升级 | 确认层；取消默认焦点；Esc 0 请求 |
| strong | 永久删除存档 | 必须输入与标题（或短 ID）完全一致的文本；确认默认禁用；输入匹配后启用；Esc 0 请求；成功后 1 次 POST |

- 删除确认正文包含：标题、短 ID、端口、会话数、不可逆说明。
- 归档确认正文必须写明“停止进程、保留 home；永久删除在归档行”，不得写“归档并删除 home”。
- 双击确认键/快速 Enter 只产生 1 次请求：确认时先关闭浮窗并置 `busy`，`onConfirm` 单飞；服务端幂等键兜底。
- 不使用 `window.confirm/prompt`（AC 静态断言）。
- 无全局破坏性快捷键；删除只能从读档视图的显式按钮进入。

### 4.4 空槽位与配额

- `slots=7` 恒定；`limit` 默认 5，可配 1–7；`used` 含 starting/reserved/paused 等占槽 phase。
- 面板显示 `配额 used/limit` 与 `槽位 used/7`；6/7 位以虚线胶囊表达“超出当前配额”，不可点击。
- `headroom=0` 且容量新鲜：M-05 前置禁用，0 请求，原因可见；容量陈旧：可点并提示“状态可能已变”，由 409 仲裁。
- 归档/删除释放槽位；UI 在下一次快照（或操作后的强制刷新）收敛，不做本地乐观扣减。
- 左栏不渲染“新建元主”空槽；工作区由宿主创建。空态只说明“宿主管理 · 只读”。

### 4.5 触屏与 hover

- `@media (hover:none)`：元主行动作常显；卡悬停位移取消；按钮悬停背景取消；展开/操作按钮 ≥34px；文本按钮内边距加大。
- 参考图依赖 hover 的“行内动作”在触屏上必须常显；不允许“只有悬停才出现关键操作”。
- 双击重命名不是唯一入口：展示态按钮可 Tab + Enter/F2；移动端长按不是必需路径。
- 触摸目标：主 CTA 40px；次级 34px；图标 34px；行内文本按钮 28–34px 且间距 ≥4px。
- 不依赖 hover 传达状态；所有状态有文字。

### 4.6 键盘地图

| 键 | 位置 | 行为 |
|---|---|---|
| Tab / Shift+Tab | 全局 | Header → 元主卡 → 搜索 → 元主行 → 会话 → 分身组 → 卡；浮窗内闭环 |
| Enter / Space | 行/按钮 | 激活；会话行切换选中 |
| Enter / F2 | EditableText | 进入编辑 |
| Enter / Esc | 编辑态 | 提交 / 取消 |
| Esc | 搜索框 | 清空搜索 |
| Esc | 浮窗 | 关闭，焦点回触发元素 |
| ← / → | 分组头 | 折叠 / 展开（按钮原生 Space/Enter 亦可） |
| 无 | 全局 | 无单键删除/归档快捷键 |

### 4.7 读屏

- 地标：`header[role=banner]`、`section[aria-labelledby]`（母体/分身）、`footer`；浮窗 `role=dialog`/`alertdialog`。
- 名称：按钮均含可见文本或 `aria-label`；展开按钮带“展开/收起 + 名称 + 会话数”；卡片 `aria-label` 含标题与状态。
- 实时区：全局 `role=status`（礼貌）与 `role=alert`（严格）各一；派生/改名/归档结果播报；统计数字不做逐秒播报。
- 状态：`data-state` 与可见文字并存；颜色不是唯一编码（色盲可读）。
- 禁用：`aria-disabled` + 可见原因 + `aria-describedby`；不只用 `title`。
- 背景：浮窗打开时背景 `inert` + `aria-hidden`，焦点不泄漏。

### 4.8 动效与降级

- `prefers-reduced-motion`：移除位移与脉冲；toast 仍显示但无滑入。
- 断线：区域标 `data-freshness="offline"`；保留上次已知卡并降饱和；横幅“上次成功 HH:MM:SS”；不得把离线写成 crashed。
- 陈旧：`stale` 时 CTA 可点但提示可能已变；错误可重试；派生失败给出出口（归档/配额）。
- 打开失败：`open-url` 失败只报错，不等价“已打开”，不回落到旧 URL。

## 6. 实现映射（`client.js` v4）

### 6.1 架构

| 层 | 做法 |
|---|---|
| 视图原语 | 单文件 `h(tag, props, ...children)`；支持 class/style/dataset/aria/on*/布尔属性；SVG 工厂；全部原生 DOM |
| 状态 | 单个可变 `S`；`refresh()` 拉 `status/tasks/sessions`；派生共享 store 单飞；浮窗/编辑/Toast 为 UI 状态 |
| 渲染 | 全量重建视图子树 + `requestAnimationFrame` 合帧；编辑中挂起；提交/取消强制渲染 |
| 焦点 | 元素 `data-fk`；渲染前记录、渲染后恢复光标；浮窗内优先保持对话框焦点；关闭回触发键 |
| 滚动 | 滚动容器 `data-sk`；渲染前后保存/恢复 `scrollTop` |
| 请求 | 统一 `api()`（鉴权头、304、诊断）；5s 轮询，页面隐藏/浮窗打开时跳过；会话仅在展开/首次出现时拉取 |
| 挂载 | 宿主 slot 返回 React 元素是硬契约：`DomMount` 15 行壳只负责挂载 DOM；无 JSX、无构建、无新依赖 |

### 6.2 数据端点（当前）

| 端点 | 用途 | 频率 |
|---|---|---|
| `GET /fang/api/status` | 母体版本、role、适配器计数、配额（capacity 可选） | 5s |
| `GET /fang/api/tasks` | 分身列表 | 5s |
| `GET /fang/api/sessions` | 母体会话（元主槽位聚合） | 5s |
| `GET /fang/api/tasks/sessions?taskId=&limit=20` | 分身会话 | 展开时；首次出现预热一次 |
| `GET /fang/api/auth-token` | 内存令牌 | 启动一次 |
| `POST /fang/api/derive` | 派生 | 用户触发 |
| `POST /fang/api/tasks/archive` / `restore` / `archive/delete` / `promote` | 分身动作 | 用户触发 |
| `GET /fang/api/tasks/open-url` | 一次性打开 URL | 用户触发 |
| `GET /fang/api/mirror/status` + backup/restore/delete/interval/upgrade | 镜像维护 | 打开浮窗时；操作后强制刷新 |
| `GET/POST /fang/api/mother-link` | 连接描述/探测 | 浮窗打开/手动 |
| `PATCH /fang/api/workspaces/:key` | 工作区别名（目标契约） | 重命名时；404/405 退化本地 |

### 6.3 状态投影与降级

- legacy `ready/running/provisioning/failed/archived` → `phase`/tone 的唯一投影表；组件不另写。
- `capacity` 缺失：`limit = tasks.max`（缺省 5）、`used = 非归档任务数`，标注“估算”。
- `phase/health/actions` 缺失：按 legacy 投影；不推断 paused/completed。
- `openable` 缺失：仍先请求 `open-url`，失败只报错。
- `actions` 缺失：只展示当前有路由的动作；工作区 CRUD、暂停/重启直接隐藏。

| `data-state` | 状态 chip | phase/legacy 归并值 |
| `data-health` | 适配器 chip | pending/ok/error/n/a |
| `data-freshness` | 左右面板 | live/stale/offline |
| `data-task` | 分身卡 | taskId |

| 能力 | 现状 | UI |

### 6.7 服务端前置（本轮未落地的契约）

| 项 | 目标（STATE-MODEL / REVIEW） | 当前 UI 行为 |
|---|---|---|
| phase/health/actions 掩码 | 快照直出，UI 只投影 | 用 legacyStatus + adapter.ok 投影；未知即中性 |
| capacity 7 槽位 / 5 配额 | 服务端账本 + headroom + checks[] | 用任务数估算，标注“估算”；满员禁用（≤5） |
| 派生 202 + opId + ghost | 受理即返回，客户端出 ghost，超时撤下 | 同步 POST；等待期间仅顶部进度条，无 ghost |
| 快照 ETag / panelRev | 304 不重建；整包收敛 | 每 5s 三请求；304 分支未接（作为回归项） |
| 任务重命名 PATCH（baseTitleRev） | 服务端 CAS + 409 | 不渲染入口；工作区别名走 PATCH，404 退化本地 |
| 工作区 PATCH 别名 | fang 自有偏好，不碰 workspace.json | 已实现调用；旧宿主 404 时本地别名 |
| 母体 pause/resume/restart | actions 掩码驱动 | 无路由 → 隐藏（capability-missing） |
| 分身 pause/resume/completed | 同上 | 隐藏；不推断“已完成” |
| open-url 409 | 只报错，不回退旧 URL | 已实现 |
| 审计/opId 回显 | 响应带 opId/auditId，UI 显示“已记录审计” | 未接；成功提示不含审计号 |
| 会话数/体积采样 | sessionCount/homeBytes TTL | 会话数用展开时实时拉取；体积未显示 |

> 这些是**服务端前置**，不是 UI 缺陷；本版按“能降级就降级、不能降级就不画”的原则实现，避免假成功与灰键诱导。
