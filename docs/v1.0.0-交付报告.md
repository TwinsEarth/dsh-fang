## 6. 两个必须记住的发现（都是真机结论）

### 6.1 客户端半的入口必须是**裸包名**

`dsh-client-modules` 的 `exactPackageSpecifier()` 只接受两段 scoped 名
（`@scope/pkg`），`@scope/pkg/subpath` 被判为 undefined → 该行**永远进不了客户端构建**。
所以 `fang-orchestrator` 行必须写成 `name: '@local/dsh-fang'`（包根入口就是它），
其余 9 行用子路径没问题（它们没有 client 半）。

### 6.2 运行中的宿主持有 ESM 模块缓存

改完插件源码后，`remove_bundle` + `install_bundle` 会重装并重放 patch 行，
但**已加载模块不会重新求值**（同一 file URL 命中 Node ESM 缓存），
`set_plugin` 关→开也只是重建 fiber。因此：

- 本次交付的最后三处修复（role-from-env、`/api/forks/create` 拆分、启动自检接线）
  **要等母体下一次重启才会生效**；
- 重启属于项目红线，必须由你确认/亲自执行，本报告不代替重启。
