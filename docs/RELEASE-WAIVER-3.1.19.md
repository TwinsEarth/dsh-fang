# RELEASE WAIVER — v3.1.19

## 跳号说明（v3.1.17 → v3.1.19）

`v3.1.18` 原计划为纯品牌文案版（改名 + 简介 + README，`package.json` 已置 3.1.18），
但该版**从未发版**：在合并前用户追加了 3.1.19 的两项界面收敛与关闭确认需求，
因此将 3.1.18 的全部内容并入 **v3.1.19** 一次性发布，避免一个只有文案的空版本。

## 影响

- npm 与 GitHub Release 上不会出现 `3.1.18`；`latest` 从 `3.1.17` 直接到 `3.1.19`。
- 3.1.18 的内容（名称/简介/README）已全部包含在 3.1.19 中，无功能缺失。
- 版本号阶梯因此跳号，按本仓库规则申请 waiver。
