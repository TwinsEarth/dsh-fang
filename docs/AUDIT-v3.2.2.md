# AUDIT v3.2.2

范围：决策等级显式化（优先级/风险）+ 收件箱四色分组常驻。

## 现场事实（2026-11-14）

```text
profile 安装版本 : 3.2.1
运行实例版本     : 3.1.34  ← 未重启，新代码未加载
决策库           : 红 5 / 灰 2，黄蓝绿 0 条
```

→ 只看到红色提醒有两个原因：(1) 运行的还是旧版；(2) 黄/蓝/绿没有记录时分组直接消失。

## 改动

| 项 | 内容 |
|---|---|
| priority/risk | 正式字段，默认由等级推导，支持调用方覆盖，落库/恢复/API 全链路 |
| ask_user_choice | 默认红，可选四色，按等级等待/自动执行 |
| 工具说明 | 明确“按风险选等级，不要全部用红色” |
| 收件箱 | 四色分组常驻（0 条显示暂无记录）；优先级/风险徽标 |
| 右栏 | 等级标题带 P/R，条目带优先级与风险 |

## 兼容

- 旧 ticket 无 priority/risk 时按等级推导，不写坏旧数据；
- `level` 缺省仍为红，既有调用方行为不变；
- 无新增 HTTP 路由。
