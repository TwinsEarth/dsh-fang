# 瓮城（dsh-Fang）术语表

> 状态：已确认（2026-11-04）。文档与代码命名以此为准，禁止混用。

## 五个实体

| 术语 | 定义 | 不是什么 |
|---|---|---|
| **母体（Mother）** | **DSH Web 官方纯净版**：唯一基座；只带官方插件；不能安装第三方插件；不能开启会话/任务/项目；可升级/回退、克隆、备份、还原；**不可删除** | ❌ 不是 PC 镜像；❌ 不是运行实例 |
| **母体镜像（Mirror）** | PC 客户端里保存的**母体备份/副本**；用于回退与快速克隆；自动备份周期 6/12/24 小时 | ❌ 不等于母体本体 |
| **运行实例（Instance）** | 母体/原身/分身被启动后的进程（端口 + token） | ❌ 不等于母体 |
| **原身（Essence）** | 从母体克隆的可配置层；可安装第三方插件、改设置、登录账户；**不能**开启会话/任务/项目；删除原身不级联删除会话，但不能再派生新分身 | 元主/本尊与之**完全同义**，代码统一用 `essence` |
| **分身（Derived）** | 从原身派生的生产层；只能会话/任务/项目；**不能**装插件/改设置；生产数据持久化，关闭再打开仍是同一 `sessionId` | ❌ 不是原身；❌ 不是分支 |

## 同义词

- **原身 = 元主 = 本尊**：完全同义；UI 可显示“原身（元主/本尊）”，代码字段只用 `essence`。

## UI 边界

| 位置 | 允许 |
|---|---|
| **PC Electron 面板** | 唯一的 fang 操作控制台：母体/原身/分身的升级、备份、派生、归档、配置、删除 |
| **DSH Web（浏览器）** | 仅 DSH 自身页面；**禁止** fang 面板、浮层、独立 HTML 路由、浏览器注入 dock |
| **DSH Web 插件 UI** | 仅 `decision-queue`，通过 DSH 官方 client 插槽注册，只随 derived profile 加载 |

## 会话与分支

- 会话文件夹归**分身**：`sessions/<forkId>/`，关闭再打开沿用同一 `sessionId`；
- 一个分身只能有一个会话；第二次开会话 → `409 session-locked`；
- 同分身同会话可有多个 `branchId` 分支，同进程多线程/多日志；
- 分支**不可合并**回父分支；
- 原身删除不级联删除会话；已派生分身继续可用。

## 删除语义

| 对象 | 删除行为 |
|---|---|
| 母体 | **禁止删除**；只能克隆/重建/备份/还原 |
| 原身 | 删除后不级联会话；已有分身不受影响；仅不能再派生新分身 |
| 分身 | 归档保留；永久删除默认连同 `sessions/<forkId>/` 一起删除（UI 二次确认） |

## 三根目录（v3.0.9 起）

1. 母体根（运行/备份/还原）；
2. 原身根（每原身独立沙箱）；
3. 会话根（按 `forkId` 归属）。

访问矩阵：仅协调器（broker）可读写三根；母体 Web 只读母体根；原身 Web 只读母体根 + 读写自己目录；分身只读所属原身 + 读写自己 session 目录；跨根一律走 broker + capability token + 审计。
